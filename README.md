Summarize DLS(Dynamic Light Scattering) data (Prometheus Panta) across SEC fractions and MV, per cell line, for visual representation in Prism / Python 
Outputs a plot of mean intensity distribution across fractions, one panel per cell line
Outputs an offset "stacked" version of each cell line's mean curves, for a clean stacked plot in Prism

Code was initially made by Ruben G. Eich and repurposed by Aimy Hebberecht to enable visual representation in Prism, with the help of Claude.ai.
